# 多图叠卡、照片标记与聊天背景感知交接

日期：2026-09-16
分支：`feat/imessage-private-chat`
基准：`5024eec fix(chat): refresh avatar context and restore offline controls`

## 需求

- 真实照片和文字图均支持一次选择/填写多张。
- 多图发送后只占一个视觉消息位置：卡片叠放、右上角动态显示“n 张照片”，可左右滑动切换。
- 点开先进入整组照片墙，再进入单张查看；用户可为照片画涂鸦/标记。
- char 连续发送多张文字图时使用同样的照片组，并具备为照片加标记的输出协议。
- char 获取当前 iMessage 会话背景，并能知道背景是否自上轮以后发生变化。

## 实现

- `components/chat/rich-input-modals.tsx`：照片选择改为最多 20 张，逐张描述、追加和删除；文字图支持多条描述。
- `components/chat/chat-room.tsx`：同批图片写入共享 `photoGroupId`，只渲染组首消息；删除组首时整组删除。
- `components/chat/message-bubble.tsx`、`components/chat/media-preview-overlay.tsx`、`styles/chat.css`：叠卡、动态张数、拖动换页、照片墙/单张层、SVG 标记覆盖与编辑器。
- `lib/chat-storage.ts`：新增照片组与标记数据结构。
- `lib/rich-message-parser.ts`、`lib/builtin-preset.ts`：连续照片协议成组，支持 `[照片标记:x:y:文字]`；角色是否发送/标记仍由角色模型决定。
- `lib/chat-engine.ts`：视觉历史限制按照片组计一个名额，但保留组内全部图片；附加当前会话背景事实与视觉。
- `lib/group-chat-engine.ts`：群聊同样附加当前会话背景事实与视觉。
- `scripts/check-chat-multi-photo.cjs`：新增多图解析、成组、标记、单次渲染、整组删除、手势入口和视觉额度回归。

## 第二轮细节补齐

- 照片组右上角改为蓝色四格图标和 `当前 / 总数 张照片`；滑动后的当前页写回消息存储。
- 叠卡按 3、4……9 张显示不同层数、偏移、旋转与缩放；超过 9 张维持九层视觉上限。
- 引用照片组时冻结当前首图的消息 ID、序号、总数、描述和标记；真实照片还把对应图片交给视觉模型，因此切到第 3 张再引用，不会继续识别第 1 张。
- 照片标记改为双通道：界面保存手绘覆盖，同时写入独立 `photo_markup_action` 事件，记录操作者、目标照片序号、颜色、位置和描述；进入视觉前把覆盖合成到原图，避免模型只看到未标记原图。
- char 可用 `[照片标记:第3张:x:y:文字]` 选择用户、自己或群成员最近照片并自主决定是否落笔；不强制标记。角色生成的文字使用手写字体呈现，不使用 emoji 冒充涂鸦。
- 用户保存标记后会触发一次角色回复机会，角色收到结构化标记事实并自行决定回复内容或保持安静。
- 更换/移除会话背景会写入系统式播报，并把事件交给角色自行判断是否回应。

## 真机反馈后的修复

- 用户确认“用户手绘 → char 识别”准确可用。
- 浏览器实际报错为 `Cannot update a component (ChatRoom) while rendering a different component (PhotoGroupBubble)`：滑动回调在 `setIndex` updater 内同步更新父组件。现已把持久化与父组件更新移出 state updater，避免 React 跨组件渲染期更新。
- 对话记录显示 char 只用自然语言声称“圈了”，没有产生 `photo_markup_action`，所以并非视觉/绘画模型执行失败，而是动作协议未输出。根因是照片标记说明只新增在内置预设源码，已有或自定义预设不保证包含它。
- 已在私聊、群聊的运行时提示组装层加入不依赖预设的能力约束：实际声称完成标记时必须同时输出照片标记协议；不想落笔时不得假装已完成。未用关键词强迫角色标记，决定权仍属于角色。
- 专项检查通过；TypeScript 仍只有既存的三条 world-builder 依赖缺失。
- char 的常见标记意图（爱心、星星、圆圈、箭头）现转换为可编辑 SVG/Canvas 路径；路径含确定性轻微抖动与错位浅描边，避免规则、光滑的图标感。模型即使误输出星形/爱心 emoji，也会转成手绘路径，事件描述保存为“手绘星星/爱心”等语义，而不是把 emoji 贴到图上。其他自由内容仍以手写呈现，不限制角色发挥。
- 未自动接入生图来做普通标记：矢量层可撤销、可记忆、不会重绘原图且无额外模型费用；复杂涂鸦的可选生图通道留待单独设计和授权。
- 照片组叠卡改为后层只在右侧单边露出；拖拽只接受从右向左，左滑进入下一张并在末张循环，右滑不再倒退。滑动后点击抑制避免误开照片墙。
- 根据真机截图再次调整手绘感：星形使用不等长半径、不对称角度、分段弯曲和轨迹抖动，避免“规则五角星图标”；圆圈、爱心和箭头沿用非完美路径与浅色复描。
- 界面上的灰色标记通知缩短为“角色名标记了第 N 张照片”；颜色、区域、轨迹与语义仍保存在结构化事件中供角色记忆/视觉识别，不再把调试式细节全部展示给用户。
