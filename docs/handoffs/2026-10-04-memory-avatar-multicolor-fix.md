# 记忆 HTML 多代表色取色修复

日期：2026-10-04。分支 `feat/imessage-private-chat`；HEAD `c3cd2d3`。用户在上一轮诊断后授权修复，本轮只修改独立记忆 HTML 的取色，不接入正式页面。

## 完成行为

- 64×64 居中圆形采样，排除透明及最暗／最亮低辨识度像素；降低阴影权重，以饱和中间调代表视觉色系。
- 10°色相分桶，合并相邻桶；以有效面积和饱和代表色评分选择最多三个不同色族的候选，过滤极少量色噪声。代表色取较明亮、饱和的实际像素，避免整片暗头发把颜色均值压成褐色。
- 对中心暖色且明亮的区域做肤色样色的软降权；有足量其他色族时将其保留为辅助色。没有显著其他色族的桃色头像仍保持桃色。这是像素启发式，不调用人脸识别／模型，也没有为用户照片硬编码绿色。
- 以主色与辅助色派生五层柔和明度／饱和度，替代单一褐色加虚构互补色。昼夜各自生成色板；黑白图使用层次灰色，失败／无图／透明图使用默认配色。
- 标题、说明、条数随实际底色保证至少 4.5:1 对比度。缓存最多 64 个头像结果、8 秒超时；旧图片请求晚到仍不能覆盖新图片。
- 英文标题、中文说明、层叠形状、第一层不变的边界均保留。公共聊天取色／气泡代码、React 页面、记忆模型规则未修改。
