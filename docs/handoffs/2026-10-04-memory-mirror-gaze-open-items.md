# 镜子、凝视与未了事项

2026-10-04；feat/imessage-private-chat；基准 c3cd2d3。仅产品讨论/记录，未改功能、未 commit/push。

确认命名：自检→镜子，含模型对人物的理解、记忆审视与当前心境；他眼中的你→凝视，含char对user的主观认识、感受、愿望等。

用户倾向：未了事项与短期、长期、核心并列，单独记录和补充更新；担忧与三层重复。工程建议尚非冻结规格：三层保存经历，未了事项为经历的当前进展视图；保存最小事项、来源引用、状态和补充更新依据，不复制整段原话/摘要。复用同一事项ID串接后续证据，不按每轮摘要新建；归并不确定时不擅自合并。完成/取消退出活动提示但保留已归档记录与经历，不能删除所有历史。构造请求统一去重，来源已包含时仅补当前进展，按相关性/预算挑选，不额外每轮全量注入。存在相同来源引用不是数据重复；重复模型叙述需控制。具体UI入口名、字段与更新触发未定。

验证：文档差异检查；无模型、浏览器或真机测试。
