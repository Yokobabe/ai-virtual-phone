# 记忆升级效果评估

2026-10-04；feat/imessage-private-chat；基准 c3cd2d3。静态评估/讨论，未改代码、未付费模型对照、未 commit/push。

核对 memory-types、memory-summarizer、core-memory-builder、memory-service、memory-injector 和 llm-prompt-assembler。既有能力已保留承诺/关系变化，所以只改措辞的边际收益有限。长期默认100-200字、默认80事件触发，存在细节压缩与状态延迟；总结输入默认为角色名字和事件，不完整人设。核心提示的要求把稳定关系与普通日常/一般情绪/推测并列，缺少纳入/排除区分：这是源码默认，不等于用户正在使用的已保存模板。

判断：仅改提示词预期小幅、情境性提升；配合来源追溯、关系/事项状态连续更新、紧凑且实际注入，跨时段/跨应用连续性预期中等、有些场景明显；人物理解可见性直接增加，但不证明准确性；不能承诺更聪明或长期不失忆，不能给未经测量百分比。

风险：画像和欲望推测被循环强化，过时心境，机械情绪规则，状态及摘要重复增加token。重要即时状态不等到固定长期阈值后才处理；镜子/凝视不是频繁全量重写，不把主观推断当设定事实，完成动作依据实际落库结果。

验证建议：同模型/参数/记录，对照旧版、提示词改版、完整最小改版；测事实细节、误解→解释、承诺→兑现/取消、跨应用衔接、人物差异、user隔离。记录来源支持率、错记/漏记、旧状态误用、重复提醒和输入/输出token/调用次数/延迟；源数据与测试世界隔离，本次不运行真实模型。保留部分场景作为未调参测试样例，用户盲评连贯性与拟真。可见性收益与扮演质量分开，证据不足不放大开发范围。
