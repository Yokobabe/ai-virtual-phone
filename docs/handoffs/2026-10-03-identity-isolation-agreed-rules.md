# 身份隔离规则整理与核对

本文件替代前两份身份诊断中与下列规则冲突的设计建议；诊断代码证据仍有效。

- 分支/基准：feat/imessage-private-chat / e57d3db。仅整理、静态核对，未实施、未 commit/push。
- 当前身份：全局身份选择是全手机身份切换入口；应用不得覆盖身份。
- 身份标识：现有 UserIdentity 已有 id，编辑保留 id；现有新增使用时间戳，实施时采用 UUID 等稳定唯一标识并保留旧 id。名字仅作显示/模型文本，禁止作为归属或权限键。新建同名身份也应独立。
- 隔离：聊天、联系人、群、关系、记忆资源库与检索、社交、钱包购物、查手机栖所、创作存档及异步任务按 userId 归属。同 char 不同 user 不共享互动状态。
- 角色库：基础角色卡共享、均可查看；已有聊天头像与档案隔离继续保留。修改共用基础人设会影响读取它的请求，互动派生状态不得写进共用卡。
- 互动权限：角色白名单可多选；未专绑所有身份可互动。删除身份后移除该身份引用，若专绑名单无有效成员则开放全部；开放权限不转移旧身份数据。
- 取消专绑：开放全部，原 user 继续聊。只有将某 user 从仍有限制的名单移除才失去权限；保留原历史，旧群该角色的新互动也受限制。
- 群聊：允许加入非好友，但只能加入当前 user 可互动 char；权限变化后已有群的新动作重新检查。
- 绑定：API/语音/预设/世界书/正则及角色应用覆盖按 userId+characterId 保存；未配置继承全局默认。世界书内容由用户管理，不分析文本分配身份。
- 迁移：存量归迁移开始时全局身份 ID，角色旧绑定配置及应用内显式身份选择也需要迁移到该空间，不得复制历史到全部身份。
- 核对证据：components/settings/user-identity.tsx 已有 id 且编辑不改 id；lib/settings-types.ts CharacterBinding 目前只含 characterId；chat-room 的群红包 claimedBy/claimedAmounts 与转账行为部分按名字匹配，需补稳定参与者标识并兼容旧数据；interview-magazine draft/session 显式 userIdentityId 不得继续跨当前空间选择。
- 未决边界：删除身份是删除其数据还是保留可恢复空间；删除当前身份的安全切换；纯桌面/主题/素材偏好归属；切换期间旧身份任务继续完成或中止及通知策略。
- 风险仍适用：缓存/多标签刷新、发起身份固定、动作权限检查、跨应用上下文检索、云任务回收、备份恢复清理、可恢复一次性迁移。
- 修改文件：本交接和 TODO。无功能变更，无模型/TTS/账号调用；未浏览器/真机验收。
