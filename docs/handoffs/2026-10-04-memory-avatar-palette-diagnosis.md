- 主色 `rgb(65,55,27)`，即 `#41371B`，深褐色。
- 原气泡派生底色 `#C3B590`。
- 五栏目实际日间颜色：FACTS `#EAE5D8`、CORE `#C8BB99`、LIST `#E9DFD6`、MIRROR `#F4F5F8`、GAZE `#C3B590`。实际 CSS 计算结果与派生输出一致。
- 当前圆形采样的有效彩色像素权重：45°桶约 35.1%，60°约 24.3%，30°约 23.1%，75°约 12.7%，90°约 1.2%。绿／黄绿色分散在多个桶，深褐色单桶胜出。
- 全图方形采样也选中相同深褐色，单纯去掉圆形裁切不能修复此案例。

## 原因与候选调整

- 单一最大色相桶偏重面积；现有阈值只排除最接近黑色的像素，较暗褐色阴影仍参与主色竞争，覆盖视觉醒目的绿色。
- 一个主色派生五色无法保留照片中的多个实际色族；邻近／互补色属于当前派生设计，并非全部从图中直接抽取。
- 待讨论改进：抽取多个代表色、降低暗阴影权重、合并相邻色族，再把真实代表色整理成低饱和浅色层次。需要保留黑白头像回退与日夜对比度；不能直接修改公共气泡逻辑影响用户已认可的聊天效果。
