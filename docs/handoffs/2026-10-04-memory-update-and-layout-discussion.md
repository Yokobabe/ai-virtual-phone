## 已核对的调用

- `MemoryCognitionPanel` 的“查看这里不会调用模型”指打开／查看已保存的认知，不是“整理更新”按钮。
- 按钮通过 `handleManualSummarize()` 调用 `runSummarizationPipeline()`；默认处理上次整理之后的新事件。没有新事件会提前提示，不调用模型；未配置总结 API 则返回错误。
- 有事件且配置有效时，使用辅助绑定 `memorySummaryApiConfigId` 的模型；输入启用来源的实际事件、角色人设、当前用户身份、已有认知与事项，在一次记忆总结请求中生成长期摘要及增量认知更新。认知更新开关关闭时不生成相应认知。
- 开启向量且配置有效时还会生成摘要向量。代码核对不等于真实模型生成验收；本轮未点击真实整理、未调用付费服务。
- 当前按钮是新事件增量总结，不是单独以全部旧记忆重做一次凝视／镜子。
- “查看不调用”与“整理会调用”的区别在当前界面表达不清；文案如何调整待授权实现。
