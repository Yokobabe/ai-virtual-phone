# 身份生命周期规则与实施检查

基准 feat/imessage-private-chat / e57d3db。仅静态审查与记录，没有实施功能或删除真实数据。替代此前交接的未决生命周期项。

## 用户确认

- 删除身份：清除该 userId 所有私人数据与 user+char 配置，包括关系网、聊天、记忆及向量、钱包、购物、社交、创作存档、查手机、栖所、任务、缓存和日志中的私人内容。共享 char 档案保留，即使仅专绑这个身份。清除专绑引用后无有效身份则开放所有身份。
- 切换身份：非当前身份静默，不主动发消息、不自动社交、不继续发起模型任务、不推送通知。切回不补发离开期间积压的主动互动。正在请求需尽力中止，晚返回不能新建旧身份互动或写入当前身份；已完成付款等一致性清算仍须归原身份。
- 外观：桌面主题继续共用，不因身份切换变化；外观多套预设记录为独立后续需求，不在身份调整审查中实施。
- 已确认规则继续适用：稳定身份 ID，编辑保留 ID，新建独立 ID；互动数据身份隔离、角色卡共享；无专绑全开放；群成员不要求好友但受权限限制；绑定 user+char；存量归迁移开始时全局身份。

## 本次代码核对新增重点

- data-management/modules.ts 当前按整个数据库/模块登记，不能直接调用模块清理删除某个身份；记忆/栖所/查手机现有删除函数按 characterId，必须增加身份范围以免误删其他 user 的同 char 数据。
- photo-album-storage.ts 删除相册素材会调用 deleteMediaRef/deleteThemeAsset；theme-storage 与 media-cache 是共享素材后端。清理身份须先检查其他身份和共享档案/主题的引用，私有无引用媒体删掉，共用媒体保留。
- chat-engine.ts 已有请求 AbortController，但没有全手机身份生命周期取消协议；本地计时、后台云快照/规则及收件也需统一静默范围。
- 删除须先封锁该身份读写与任务，再删除各库，校验完成后删除身份入口；失败可重试，不能用删除身份卡后 fallback 第一张卡来替代。延迟返回与云同步不得重建已删数据。
- 删除当前身份需退出当前应用，选择存活身份；最后一张身份删除后进入无身份状态，禁止互动，不自动恢复默认样例身份。现有 UserIdentitySettings 空列表会自动写入默认身份，须区别首次初始化与用户删空。
- 身份列表与专绑是共享元数据；名字不是主键。配置名单清理不能删除 char；删除重建同名身份不能认领旧数据。
- 云端受应用管理的数据/任务必须按身份清除；已经导出的本地备份、第三方外部聊天不能承诺随应用删除，恢复备份应为显式恢复操作。
- 多标签页须接收切换/删除事件；持有旧身份的页面失效。云端静默不能只依靠浏览器卸载或隐藏页面。

## 实施验收门槛

1. A/B 同 char 历史、记忆检索、查手机、栖所、钱包等互不出现对方数据。
2. 编辑/重名/删除重建，均按 ID 正确归属。
3. 非好友可加群；专绑限制覆盖群、工具、好友请求、分享及自动行为；名单删空全开放。
4. 生成/语音/通话/付款/记忆总结期间切换，旧身份静默，返回不串写；切回不补发积压任务。
5. 删除身份覆盖全部私人存储、缓存、索引、云任务；另一身份和共享角色/主题素材仍完整。
6. 删除当前/最后身份、删除中断后重试、刷新和多标签页、备份恢复均有对应测试。
7. 一次性存量迁移锁定原全局 ID，可恢复，迁移失败不进入半迁移状态。
