# 现有记忆能力澄清

2026-10-04；feat/imessage-private-chat；基准 c3cd2d3。仅静态核对，未改功能、未模型调用、未 commit/push。

用户询问原话依据和未了事项是否已存在。现有原生记录被统一时间线读取且总结不删除原文；长/核心条目记录时间跨度和部分来源会话。MemoryEntry 已有可选 sourceMessageIds，但自动长期及核心写入不填逐条原话ID，核心也不关联输入长期条目ID；记忆卡界面只展示正文/日期/编辑删除，没有依据跳转。不能称完全没有原话基础，也不能称已做到逐条证据追溯。

默认总结明确保留承诺、情感变化和关系里程碑；手动记忆也可记录约定，并随检索注入。当前记忆类型/整理链路没有专门的未履行→兑现/取消状态、前后依据和优先召回机制。应用自己的日程/提醒不等于统一记忆中的开放事项。候选应为增强现有能力，非重复另造模块；是否独立UI尚未决定。
