# 记忆五层头像配色与英文标题预览

日期：2026-10-04。分支 `feat/imessage-private-chat`；HEAD `c3cd2d3`。叠加独立 HTML 原型，未接入产品。

## 用户要求与范围

- 五栏目配色跟随 char 档案头像，采用类似现有头像／气泡的取色方式，保持参考图柔和层次。
- 只移除栏目中文标题，统一 FACTS、CORE、LIST、MIRROR、GAZE；中文说明保留。
- 第一层用户身份＋角色头像横幅列表不改。用户指出原型的简化第一层不是目标，已移除该演示；原型只展示第二层栏目与静态内容返回。

## 实现与事实核对

- 核对 `lib/avatar-name-color.ts`：40×40 居中圆形裁切，忽略透明与近黑／近白像素的色系干扰，24 色相分桶按面积加饱和度选择主色；无彩色时返回平均灰度，无法读取时回退，8 秒超时、最多 128 项缓存。
- 核对 `lib/chat-bubble-colors.ts` 的 `avatarBubblePalette`：依据原头像色相、饱和度、曝光生成日夜柔和气泡底色。已有私聊头像可与档案分离；本需求指定来源为 Character.avatar，不使用聊天 session 头像。
- 原型内直接嵌入上述两个现有模块经 TypeScript 转译的代码快照，生产库文件未修改；随后从气泡底色派生五层深浅、邻近色与接近白色的淡对照色。黑白头像生成不同层次的浅灰，夜间为低亮色块。说明文字按实际背景对比度调整，至少 4.5:1。
- `window.memoryPreview.applyCharacterAvatar({avatar})` 是原型输入协议；新头像加载期间重置色板，旧请求晚到不能覆盖新头像。无头像、透明、加载失败回退默认配色。
- 独立 3014 原型不能直接读取 3003 的浏览器档案库；提供“用角色头像试色”本地图片选择，不上传、不写档案。未来正式接入需传当前 Character.avatar，本轮未接入真实档案或实现跨源桥接。
