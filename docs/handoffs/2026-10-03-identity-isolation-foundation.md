# 身份隔离改写：基础边界阶段

## 需求与基准

用户授权开始身份隔离改写并建立安全提交节点。功能基准 e57d3db；改写前检查点 7ab09a5（仅追加确认的设计与核心指令）。其他任务未提交改动继续保留，回退不得使用 reset --hard 清掉共享目录。

## 本阶段实际实现

- lib/identity-space.ts：稳定 ID 状态、初始旧身份归属、切换版本、身份租约、角色互动白名单、删除封锁/完成状态、可重试清理、任务取消。
- lib/identity-host-context.ts：宿主固定身份上下文，user+char 键，user+app 存储适配接口；提交前回查边界。
- lib/identity-space-db.ts：独立 IndexedDB 元数据/私有记录/权限表，user 及 user+module 索引；写入与身份校验同事务，另标签切换无法绕过；删除只按 userId 清理，名单删空开放，最后身份为空且不会重新初始化。
- scripts/check-identity-space.cjs：隔离核心/SDK适配行为测试。
- scripts/check-identity-space-idb.cjs：独立随机端口和临时 Edge 浏览器真实 IndexedDB 回归，不打开用户 Float origin。
