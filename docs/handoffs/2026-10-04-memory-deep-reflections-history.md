# Mirror / Gaze 深度认知与版本历史

2026-10-04；分支 `feat/imessage-private-chat`，HEAD `c3cd2d3`。基于工作区已实现、尚未提交的记忆认知/分层页面继续修改，保留其他窗口的改动。未 commit、push、部署或调用真实付费模型。

## 需求与本轮范围

Mirror / Gaze 从表面总结改为角色视角的深谈；新版融合旧认识，每次成功产生的新认识单独存档，可回看。仅改认知提示、保存与历史入口，不调整角色库、头像取色、其他应用或身份切换体验。

| 元素 | Before | After | Why |
| --- | --- | --- | --- |
| 认知生成 | 四种认知统一最多160字 | Mirror/Gaze 完整剖析通常250–600字，另有140字内演绎提要 | 让角色动机、矛盾与变化得到展开，同时控制日常注入 |
| 历史入口 | 当前文字，无版本入口 | 沿用栏目色板的历次认知折叠入口，时间/当前标记/展开原文/来源，分页加载 | 回看每次认识，不改变现有导航或产生模型调用 |

## 实际模型输入

- 执行原文：`lib/memory-cognition.ts` 的 `MEMORY_COGNITION_PROTOCOL`，由 `lib/memory-summarizer.ts` 的原总结请求作为 system 注入。用户总结模板、角色档案/表达习惯、当前用户身份、本批事件及已有认知仍在 user 消息提供；没有新增第二次分析调用。
- Mirror/Gaze 第一人称：从具体行为深入动机、需要、恐惧、防御、盲点和矛盾，解释它们如何影响选择；Mirror 审视角色如何理解自己与发生的变化，Gaze 深入角色如何看待这个用户、期待与顾虑、给予与索求、靠近与退让。按证据择重点，不机械填心理学清单，不凭空造创伤或替用户确认内心。
- 新版读取此前**完整**当前认知，融合仍成立的旧认识与本批经历，修正被新证据动摇的判断，保留未解张力与关系来路。旧版是历史快照，不把全部历史再次输入总结，也不逐版拼接扩大上下文。
- 输出保持 JSON 协议；Mirror/Gaze 增加 `digest`，正文宽松验证上限1200字符，提示要求上限900字；emotion/mood/summary/未了事项原协议保留。新增证据必须来自本批真实事件，正文与提要结论一致；认知证据合并旧+新、最多24条，历史快照独立保留各自依据。
- 日常聊天 `formatCognitionForPrompt` 使用当前 digest；旧数据没有 digest 时按预算截取现有正文，分别预留 Mirror/Gaze 空间，避免长 Mirror 挤掉 Gaze。预算配置保留，历史仅供用户查看，不进入聊天请求。认知关闭时仍不注入。

## 存储、迁移与边界

- 记忆 DB v5 新增 `cognition_history`，复用按 userId 分库；索引按 characterId + facet + recordedAt + id。历史记录保存全文、提要、来源、依据截至时间、生成时间及内部版本 ID；Mirror 版本还保留当时情绪和心境。
- 新生成认知有独立 revisionId，重复生成相同正文也能各自留存。已有无版本 ID 的认知使用稳定旧版键迁移，状态修改或重复读取不会增生版本。版本 ID 不显示给用户。
- 迁移旧库、恢复的高版本库缺 store 或索引时修复；现存 Mirror/Gaze 先存为历史。保存时先保护旧状态，再保存新版本与当前状态；已有历史键不覆盖。只改未了状态或 null 认知更新不产生额外 Mirror/Gaze 版本。
- 长期摘要、当前认知、历史在同一事务写入；同步/异步 clone 错误或事务内并发检查失败全部回滚。总结仍检查生成过程中的身份/权限/状态变化。
- 重新总结较早时间段：保留新生成的历史版本，但不会倒退当前认知；当前版本有明确标记，不等同于生成时间最新的历史行。
- 历史不参与长期条数自动淘汰。原数据管理记忆模块未限定 stores，整库备份/恢复覆盖新 store 与索引；身份删除按私有 DB 清理，其他身份及共享角色档案保留。该路径静态复核，未在真实用户备份上执行恢复或删除。
- 此前已经被旧实现覆盖的更早文字无法凭空恢复。本轮保护目前仍存在的认知和之后成功保存的新结果；未直接修改用户浏览器数据。

## 页面与成本

Mirror / Gaze 上方增加“查看历次镜子/凝视”。点击才读取本地历史，每次10条；展开某版可读全文、时间与原话依据，加载更早版本继续分页。键盘可操作，沿用头像色板/日夜主题与单个顶部返回。查看不请求模型。下一次总结采用新规则；用户可通过原有整理范围选择全部历史重新整理，长历史继续按现有分批流程处理。
