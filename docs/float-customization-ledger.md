# Effy 的 float 二改：成果与后续记录

更新：2026-09-11。此文档是长对话的接续索引，后续每轮有实质变更时应更新；不是所有功能已完成验收的承诺。

## 首要目标与原则

- 按 Effy 的喜好修改 float 源码，形成持续维护的二改版本。优先服务自己的完整使用体验，不为可分发性牺牲核心功能。
- 保留功能，视觉尽量向 iMessage / iOS 的克制、清透、细致靠拢，而非逐像素复制。
- 适合独立使用的 CSS / 插件，后续整理为社区分享资源；完整源码改动和可安装资源包是两条不同的分发线。
- 尊重原项目开源许可与署名；发布前核对许可、素材授权、版本兼容和隐私。开源不代表任意素材都可再分发。
- 除明确要求，不提交、不推送、不上传。测试不发送真实 AI 消息、不改聊天数据。
- 本地地址固定 http://127.0.0.1:3000/。不要为启动方便改成 3001；不同 origin 的本地数据相互隔离。

## 已实现 / 已迭代的二改成果

以下基于本对话实施记录；“已实现”不等于手机、暗色、所有消息类型都已完整验收。

### 私聊、群聊共用外观与交互

- iMessage 风格气泡、尾巴、玻璃输入框与功能菜单；输入框圆角调整并保留主题 / 信息两栏。
- 聚焦输入或有文字时显示发送按钮，否则显示语音入口；独立发送与触发 AI 回复分工。保留回车发送设置，后续持续回归。
- 移除 emoji 文字联想候选；贴图候选独立显示、与输入区域对齐、限制尺寸并等比适配。
- 引用手势降低触发门槛：横向锁定约 5px，触发约 8px，容忍一定斜滑；菜单打开后禁用引用。手机手感需继续验收。
- 引用排版取消不必要缩进；思考入口放入引用结构内；引用连接线端点视觉整理。
- 系统消息菜单使用统一玻璃视觉；翻译保留原文，配分隔与小字号译文，可展开 / 收起。
- 地图卡改用 SVG pin、示意路线及图片右下角 Maps 标识，缩小卡片；转账与地图尺寸统一方向已落实。红包压尾巴的间距问题曾修复，需媒体混排回归。
- 主功能菜单去除重复视频通话、语音通话、语音条入口；改为直接长按拖动排序，无箭头或排序说明；松手后保存顺序，拖动使用逐帧位移。
- 私聊 / 群聊连续气泡间距统一为紧凑方向；两者字号与内边距仍有差异，不应称为完全相同尺寸。

### 群聊辨识与 Tapback

- char 头像绑定一组回复末条消息底部；名字位于首条上方、对齐文字起点；备注优先使用私聊备注，再回退角色名。
- 群成员切换的组间距与同人连续气泡间距分开处理；群聊更紧凑。
- 群头像支持自定义（本地 / URL），默认保留组合头像；设置入口统一字号。
- 从头像本地取色，用于群成员名字；头像更新时重新取色，无彩色或提取失败时回退灰色。
- Tapback 不应强制每条回复都出现；支持 emoji 动作解析和按参与者记录群聊反应，堆叠概览与展开详情。
- 私聊更换反应需真实更新数据而非只在台词中宣称；模型执行效果仍应实测。
- 群聊模型动作当前不应宣称支持任意历史消息定位；本轮没有扩大历史上下文发送范围。

### 日夜、背景与未读

- 聊天页跟随系统日夜模式；壁纸本地亮度采样，用于深色壁纸下的引用、名字等对比度适配。跨域取色失败不上传或代理图片。
- 移除整片 header / bottom 遮罩；气泡自身保留边缘淡化，文字头像不随整片蒙版消失。
- 优化输入提示、引用气泡 / 连接线、群成员名字、时间等暗背景显色。
- 转账与礼物卡补充夜间表面、文字、状态、分隔线，转账详情同步处理。其他页面 / 卡片尚未全部适配。
- 新增未读计数、已读处理；返回按钮内含未读数字胶囊，和箭头居中对齐；消息首页蓝点与未读过滤读取未读状态。
- 夜间迭代明细另见 chat-night-mode.md；每个后续定稿页面都需补日夜适配。

### 消息首页

- 参考列表行：圆头像、名字和时间同排、两行预览、细分隔线；保留名字旁装饰性认证勾（不代表真实安全认证），不显示在线绿点。

## 会话级「气泡改色」原始需求

用户意图（历史记录；最新实现见下）：

- 设置仅影响当前聊天窗口，不修改角色头像或其他窗口颜色。
- 私聊：user 手动颜色；char 支持自动头像取色 / 手动选色。
- 群聊：user 手动颜色；char 同样支持自动 / 手动。手动是全群统一色还是按成员设置，尚待确定。
- 浅色自动配色以白底为基础叠少量头像色，不还原原始色、不做高饱和色块。
- 建议保留经典蓝 / 灰复位选项；夜间需独立使用深底淡染，不能直接套白底。手动颜色需处理文字对比度。
- 名字沿用已有取色；尾巴跟随气泡；地图、转账、礼物等有自身样式的卡片默认不染色。
- 推荐新增配置默认保持现有经典模式，实验不直接变成全局默认；待用户确认。

## 其他遗留与未来构想

### 2026-09-12：手动配色修复、应用范围和记录

- 手动模式不再依据气泡明暗改文字颜色；黑字黑底、同色文字均按用户选择保留。对比度平衡仅用于 char 自动头像配色。
- 编辑使用同步草稿引用合并每个颜色 / 透明度字段；配置迁移为独立 KV 数据，不再随普通聊天会话写回而被旧快照覆盖。没有新配置时仍读取旧会话的 bubbleColors。
- 气泡底色与尾巴先作为不透明背景层绘制，再整层应用透明度，文字独立绘制；覆盖预览、普通消息、引用回复和流式气泡，避免接缝处重复叠色。
- 移除色谱和 RGB 滑杆入口，保留网格 / HEX / 不透明度，新增「应用范围」页面：当前聊天 / 全部聊天，显式点击应用。
- 使用递增版本确定覆盖顺序：最新全局覆盖所有旧设置，也影响未来新会话；之后的新本地配置仅覆盖该会话；再应用全局会再次统一。
- 关闭已编辑的面板或点击应用时记录完整方案，支持载入历史方案到当前聊天，再自行决定是否全局应用。不记录每个拖动帧；不把切换历史直接视为全局覆盖授权。
- 回归检查通过：手动黑字黑底、透明度保留颜色、全局 / 本地优先级、新群继承、历史载入、持久化读写。类型检查仍只有已有三个 world-builder 缺依赖错误。预览服务因 4GB 堆内存耗尽退出，已原地址重启；浏览器停在连接错误页，最新视觉需重新加载验收。
